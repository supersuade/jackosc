Output pipeline

raw → curve → smoothing → gate → invert → min-change → OSC

  • curve: linear, log (compresses quiet content), pow (accentuates peaks).
  • smoothing: attack (rise) and release (fall) times in ms; 0 = instant.
  • gate: opens when the value ≥ gate_on, closes when < gate_off (default half of on); closed output is exactly 0.
  • invert: outputs 1 − x; a gated-off value stays 0, not 1.
  • min-change: skips sending when the change is smaller — fewer packets, latest-value semantics.
  • Onset uses its own pulse decay instead of curve/smoothing; multiband applies the stage per band (no gate); Hz outputs (dominant/centroid/pitch) skip invert/gate unless normalized.

Calibration

  • Auto-calibrate captures ~3 s of raw values, then sets bounds from percentiles: frequency_map p2/p98 of band energy (spike-robust), onset p95 of flux (~5% of frames trigger), multiband per band p2/p98.
  • Until calibrated a rule outputs NaN — nothing is sent and the meter shows —.
  • Calibrate on typical material — not silence, not the loudest moment — and re-calibrate if the source gain changes.

Window & latency

  • window = FFT size in samples; hop = window advance (512 = 50% overlap).
  • Bin width = sample_rate / window ≈ 46.9 Hz @ 48 kHz; analysis latency ≈ window / sample_rate ≈ 21 ms.
  • pitch adds ~2/fmin of buffer latency (≈ 50 ms at fmin = 40 Hz) for accurate low frequencies.
  • Smaller window → finer time, coarser frequency; larger → the opposite.

Settings & JSON

  • OSC rate: send cadence (messages or bundles per second). Bundles send at most one per cycle, only when something changed.
  • auto-connect: treat empty channel connect as "auto" (system:capture_N); an explicit "auto" always connects; empty = leave unpatched for a patchbay (qjackctl/Catia).
  • cb warn: the status dot turns red when the callback p99 exceeds this (µs); empty = 25% of the period budget.
  • JSON-only settings: version and auth_token (config file or JACKOSC_AUTH_TOKEN; never shown in the UI). The raw JSON panel is for bulk edits and pasting profiles.
